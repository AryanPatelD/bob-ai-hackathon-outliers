Core Capabilities

Every tool an operator needs

Six integrated analytics layers, chained from raw data to IBM Bob conversation.

📈
24-Hour Load Forecasting
XGBoost model with 14 features including temporal lags, rolling means, and weather. Chronological 70/15/15 split. No data leakage. Produces per-hour demand forecast with model metrics.
ML Model
☀️
Renewable Generation Models
Physics-based solar (GHI × cloud transmissivity × temperature derating) and wind (cubic power curve + air density correction) expected-generation models. Every step is transparent and auditable.
Physics
⚠️
Demand Spike Detection
Reserve-margin threshold engine classifying each forecast interval as LOW / MEDIUM / HIGH / CRITICAL. Configurable thresholds. Continuous risk score [0–1] per hour. All parameters env-variable driven.
Rule-based
🔍
Asset Anomaly Detection
Compares actual vs expected generation using performance ratio and absolute deviation thresholds. Critical safeguard: nighttime and calm-weather periods are never flagged as anomalies.
Rule-based
🧠
Evidence-Based Root Cause Analysis
Separates weather-explained losses from unexplained losses. Returns confidence-scored cause candidates (cloud cover, irradiance, temperature derating, inverter fault, curtailment). Never claims mechanical failure without evidence.
Heuristic RCA
⚡
Grid Optimisation Engine
Priority-order dispatch: BESS discharge → demand response → backup for deficits; BESS charge → flexible load → export → curtailment for surplus. All SOC and power constraints enforced. Transparent per-interval actions.
Deterministic
🔋
Curtailment Minimisation
Calculates potential curtailment, BESS absorption, flexible load absorption, export, unavoidable curtailment, and avoided curtailment per interval. Full transparent arithmetic breakdown with explanation text.
Arithmetic

Ask Bob anything about the grid

Bob calls 9 MCP tools that hit the GridWise FastAPI backend directly. Every answer cites its source — model prediction, rule-based result, or heuristic estimate. Bob never invents a number.

💬"What are the grid risks over the next 6 hours?"
💬"Which renewable assets are underperforming and why?"
💬"How can we handle tonight's demand peak?"
💬"How much renewable curtailment can we avoid?"
💬"Generate the operator optimisation brief."

=== ASSET DIAGNOSIS: SOL-02 [HEURISTIC RCA] === Expected: 63.0 MW | Actual: 11.5 MW Weather explained: 1.7 MW Unexplained: 49.8 MW [52%] inverter_or_string_issue: Unexplained loss of 49.8 MW (perf ratio 0.18) suggests possible inverter failure, string disconnection, or soiling. INSPECTION RECOMMENDED Unexplained loss of 49.8 MW warrants on-site inspection.
Data type labels: [HEURISTIC RCA] — not a mechanical certainty. All values fetched from GridWise backend, not generated by Bob.
